# Einfaches-Klassifikationsmodell
Modell nutzt die logistische Regression und berechnet die Wahrscheinlichkeit für eine bestimmte Klasse. Der Schwellenwert beträgt 0.5 und teilt die Daten in zwei Klassen ein.

Bevor sie das Programm ausführen, stellen sie sicher dass sie die Bibliotheken matplotlib und scikit-learn im terminal heruntergeladen haben. 

Der Dateipfad muss auch individuell angepasst werden. Einfacher ist es wenn sie einen relativen Dateipfad nehmen.
